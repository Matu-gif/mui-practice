# MUI 管理アプリ演習

Vite・React・TypeScript・Tailwind CSS で作った Web アプリです。まず画面表示と GitHub Pages への公開を確認し、次に MUI の UI コンポーネントを学びながら管理アプリを作ります。

## ローカルで起動

```text
npm install
npm run dev
```

ターミナルに表示された URL をブラウザで開きます。現在の確認画面は、青い背景に白い「こんにちは」です。

## ビルドと公開

```text
npm run build
```

ビルド成果物の `dist` は、`main` ブランチへの送信後に GitHub Actions から GitHub Pages へ公開します。進捗は [tasks.md](tasks.md) に記録します。

公開ページ：[MUI 管理アプリ演習](https://matu-gif.github.io/mui-practice/)
