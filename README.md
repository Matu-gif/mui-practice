# MUI 管理アプリ演習

Vite・React・TypeScript・Tailwind CSS を土台に、MUI を学びながら作るアニメ視聴管理アプリです。学習と制作のゴールは[授業の目的.md](授業の目的.md)、アプリの機能は[要件定義.md](要件定義.md)に記録しています。

## ローカルで起動

```text
npm install
npm run dev
```

ターミナルに表示された URL をブラウザで開きます。作品追加フォームと一覧のコードを実装済みです。現在の表示・動作の確認状況は[tasks.md](tasks.md)を参照してください。

## ビルドと公開

```text
npm run build
```

ビルド成果物の `dist` は、`main` ブランチへの送信後に GitHub Actions から GitHub Pages へ公開します。進捗は [tasks.md](tasks.md) に記録します。

公開ページ：[MUI 管理アプリ演習](https://matu-gif.github.io/mui-practice/)
